# Day 01 – Blink LED

## Objective

To understand the basic STM32 development workflow and control an LED using Embedded C.

## Project

The first practical exercise was to blink an LED using the STM32 Blue Pill.

## Concepts Learned

- STM32 GPIO basics
- GPIO output configuration
- Digital HIGH and LOW states
- LED control
- Delay implementation
- Basic Embedded C structure
- STM32CubeIDE project workflow

## Implementation

The LED is configured as a GPIO output. The program continuously switches the GPIO between HIGH and LOW states with a delay, producing a blinking LED.

## Files

- `Blink_led_code.c` – Embedded C source code for LED blinking
- `Blink LED File` – Day 01 reference material

## Outcome

Successfully understood the basic process of configuring a GPIO output and controlling an LED using STM32 Embedded C.
